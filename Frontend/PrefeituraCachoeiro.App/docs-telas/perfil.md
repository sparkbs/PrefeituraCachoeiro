# Tela Perfil de Usuário

A tela de **Perfil de Usuário** permite ao usuário visualizar e editar suas informações pessoais e de acesso.

## Visão Geral

- **Visualização dos dados do usuário**
- **Edição de informações pessoais**
- **Alteração de senha**

## Fluxos e Funcionalidades

### 1. Visualização do Perfil

- Exibe nome, e-mail, perfil e demais dados do usuário

### 2. Edição de Dados

- Permite editar nome, e-mail e outros dados pessoais
- Salva alterações via API

### 3. Alteração de Senha

- Permite alterar a senha de acesso
- Validações de segurança

## Usabilidade e Experiência

- Feedback visual (loading, toasts)
- Prevenção de erros e confirmações de ações críticas
