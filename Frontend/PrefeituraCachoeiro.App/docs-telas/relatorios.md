# Tela Relatórios

A tela de **Relatórios** permite a visualização de relatórios de medições, projetos e históricos, incluindo integração com PowerBI.

## Visão Geral

- **Seleção de tipo de relatório** (por medição, histórico, PowerBI)
- **Visualização dinâmica** dos dados
- **Filtros avançados** conforme o tipo de relatório

## Fluxos e Funcionalidades

### 1. Seleção e Visualização

- Usuário escolhe o tipo de relatório desejado
- Sistema exibe os dados correspondentes
- Possibilidade de exportação ou integração com PowerBI

## Usabilidade e Experiência

- Feedback visual (loading, toasts)
- Layout responsivo e acessível
- Filtros dinâmicos

## Principais Funções
- Relatórios por medição
- Relatórios históricos
- Visualização via PowerBI

## Fluxos
1. Selecionar tipo de relatório
2. Visualizar relatório
