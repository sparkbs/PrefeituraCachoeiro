# Tela Home

A tela inicial do ProjetaApp dá boas-vindas ao usuário e apresenta atalhos para as principais funcionalidades do sistema, de acordo com o perfil do usuário.

## Principais Elementos
- **Cards de Acesso Rápido**: Projetos, Contratos, Clientes, Medições.
- **Mensagem de boas-vindas**.

## Funcionalidades
- Navegação rápida para as principais áreas do sistema.
- Exibição de cards condicionais conforme permissões do usuário.
